# Contador Compose

 

Nome: Ranyelle Rayssa De Melo 

 

## Sobre o projeto

 

Este aplicativo foi desenvolvido utilizando Jetpack Compose.

O estado do contador é armazenado com rememberSaveable e mutableStateOf. Sempre que o valor é alterado pelos botões, o Compose detecta a mudança e recompõe automaticamente a interface, atualizando o número exibido.

 

## Desafios implementados

 
- D2: Botão Zerar
  
- D3: Persistência na rotação de tela

- D4: Mudança de cor conforme o valor do contador# Contador_kotlin
